## 2. 色彩系统

### 2.1 种子色

**雾蓝 Misty `#3D6B9E`**（RGB 61, 107, 158）
与白字对比度 **5.5 : 1**（WCAG AA 达标），可直接作按钮填充底色。

### 2.2 Light 模式 Token（设计稿基准）

派生规则用 color-mix 表述（实现时预计算成静态 hex 进 theme，禁止运行时混色）：

| Token | 值 / 规则 | 用途 |
|---|---|---|
| `primary` | `#3D6B9E` | 主操作、激活态、强调 |
| `onPrimary` | `#FFFFFF` | primary 上的内容 |
| `primaryContainer` | mix(accent 14%, #FFF) ≈ `#E4EAF1` | tonal 容器、用户气泡、激活导航 |
| `onPrimaryContainer` | mix(accent 62%, #0E1420) ≈ `#2B4A6E` | 容器上文字 |
| `background` | mix(accent 6%, #F7F7F5) ≈ `#EFF1F4` | 页面底 |
| `surface` | `#FFFFFF` | 卡片、代码容器 |
| `surfaceVariant` | mix(accent 5%, #FFF) | 侧栏、输入域底 |
| `outline` | mix(accent 7%, #E7E7E3) ≈ `#E1E3E3` | hairline 边、分割线 |
| `success` | `#14662E`（点 `#2E7D43`） | 在线、diff 新增 |
| `danger` | `#B3261E` | diff 删除、回滚 |
| `diffAddBg / Fg` | `#E9F4EA` / `#146C2E` | diff + 行 |
| `diffDelBg / Fg` | `#FCEBEA` / `#B3261E` | diff − 行 |
| `ink`（过滤芯片选中） | `#26282E` 实心 + 白字 | 列表过滤选中态（dsh-Go 范式：安静、不用主色） |
| 代码 kw / fn / str / base | mix(accent 68%, #12203A) ≈ `#2B4A6E` / `#2E5E9C` / `#0F766E` / `#3E4048` | 语法高亮 |

### 2.3 暗色模式

v1 必须支持（跟随系统）。策略：用 Material Color Utilities 由种子色生成 tonal palette，按 M3 dark 角色取值（primary→P80，container→P30 等）；浮层材质换暗底（见 §5）。**本稿先交付 Light 基准，暗色全量出图列入 v1.2。**

### 2.4 动态取色

Android 12+ 支持跟随壁纸取色（`dynamic_color` 包）；雾蓝为品牌基线与旧设备兜底。设置中提供「品牌色 / 跟随壁纸」开关，默认品牌色。

### 2.5 主色使用纪律（dsh-Go 范式）

**一屏至多一个主色实心元素**（主按钮或选中态）。FAB、发送键、批准键、选中的过滤滑块以外，别处少用；中性色承担 ~90% 的界面，色只给「需要注意」的状态。

## 3. 排版

**字体**：全部系统栈，不打包字体文件——中文 PingFang SC（iOS）/ 系统默认（Android Roboto+平台中文字体）；代码 SF Mono / Roboto Mono / Menlo 等宽栈。

| 角色 | 字号 | 字重 | 字距 | 行高 | 场景 |
|---|---|---|---|---|---|
| Display | 22sp | 500 | **−0.02em** | 1.2 | 页面大标题 |
| Title-lg | 17sp | 500 | −0.015em | 1.25 | 推入页标题 |
| Title | 14sp | 500 | −0.01em | 1.3 | 会话标题、栏目标题 |
| Body | 13sp | 400 | 0 | **1.6** | 消息正文 |
| Caption | 11.5sp | 400 | +0.01em | 1.4 | 状态副文本、时间 |
| Micro-label | 10.5sp | 500 | **+0.08em** | 1.2 | 分组标签、tab |
| Code | 12sp | 400 | 0 | 1.65 | 代码块、diff、命令 |

规则（Apple §15）：**字距随字号反向变化——大标题收紧、小标签放松**，永不全局统一字距；层级靠「字重 + 字号 + 行高」组合而非单拉字号；全部用 `sp` 尊重系统字体缩放，布局弹性化防大字溢出。

**双字体系统（"人话 + 机话"，dsh-Go 范式）**：等宽字体只承载机器内容——代码、文件名、路径、diff 增删数、token 数、耗时数字；其余全部无衬线。数值配单位时数字用等宽/`tabular-nums`，**单位小一号、次要色**（「23 秒」「3.4 万 tokens」）。

## 4. 布局骨架

### 4.1 手机（< 600dp）
- 单栏；**底部导航 3 tab**：设备 / 会话 / 设置（图标 + Micro 标签）
- FAB「扫码添加」悬浮右下（bottom 96dp），仅设备页出现
- 聊天页**沉浸式**：浮动半透明顶栏 + 浮动输入栏，内容从两者下方穿过（见 §5）

### 4.2 平板 / 横屏（≥ 600dp）
- **双栏导航壳**：左侧 248dp 常驻导航 + 右侧内容区
- 导航结构：App 标识 → 设备组（名称 + 在线点 + 会话计数）→ 当前设备会话组（时间分组 + 激活项高亮）→ 底部设备状态胶囊
- 大屏（≥840dp）预留第三栏（右侧详情 30%），见 §4.3

### 4.3 断点（dsh-Go 实测策略）

| 窗口 | 判定 | 布局 |
|---|---|---|
| 手机竖屏 | 宽 < 600dp | 单栏；抽屉 / 推入页 |
| **手机横屏** | **高 < 480dp，不论多宽** | **坚持单栏居中**（两栏会把每栏挤成缝）；键盘弹起时顶栏淡出让位 |
| 中屏 | 宽 600–840dp 且高 ≥ 480 | 单栏；详情用加宽底部弹层（半高/全高） |
| 大屏 | 宽 ≥ 840dp 且高 ≥ 480 | 导航侧栏 + 会话列 + **右侧常驻详情栏**（宽 30%，会话列至少 400dp） |

**阅读宽度**：会话/正文内容列最大 720dp 居中，不随窗口拉满；浮在列上的控件（输入条等）696dp。底部弹层最宽 640dp 居中；对话框 280–560dp。
**安全区镜像**：横屏时左右安全区取大者、两边一致，内容居中；背景铺满到边，内容与浮层键让开安全区。

## 5. 材质与层级（Apple 融合）

- **浮动 chrome**（聊天顶栏、输入栏、底部导航）：`surface 72% 不透明 + blur(18px) + saturate(170%)`，临内容侧一道 1px 高光 hairline（`rgba(255,255,255,.45)`），无硬边框。
- **结构区域**（平板侧栏）：**重材质**——不透明 tinted（surfaceVariant），不用 blur。材质越重层级越深；禁止轻材质叠轻材质。
- **分割线策略**：默认无边框，靠留白 + 双层柔和阴影分层；**卡片内的行之间不画线**（dsh-Go 范式：靠行高和留白）；chrome 与内容交界用 16–20dp 滚动渐隐遮罩替代硬线。
- **阴影**：卡片 `0 1px 2px rgba(28,38,54,.05) + 0 4px 14px rgba(28,38,54,.07)`；FAB / 发送钮 `0 6px 18px accent 32%`（阴影带主色）。
- **Vibrancy**：半透明层上文字 weight ≥ 500、字距微增，不用纯灰。

## 6. 视觉节奏量化（dsh-Go 范式）

| 项 | 规定 |
|---|---|
| 间距 | **全部 4 的倍数**。页面内容左右 16；分组之间 24；分组标题到卡片 8 |
| 行高 | 列表行 单行 52 / 两行 64 |
| 圆角 | 卡片 20；弹层 28；小标签 8；胶囊与圆钮全圆 |
| 主色实心 | 一屏至多一个（§2.5） |
| 分隔 | 卡内行间不画线；分组之间靠 24 间距 |
| 状态表达 | 状态 = **色点 + 文字**（绿点=运行中/在线），不用彩色胶囊喊叫；选中 = 浅灰圆角底或蓝色对勾；过滤芯片选中 = 深炭黑 `#26282E` 实心白字 |
| 图标 | Lucide 单一 Family；默认 20 号线性、次要色；标签不必配图标；图标底色只在枢纽页分组用 |

## 8. 动效与手感（Apple Design → Flutter）

- **按压即时反馈**：pointer-down 即缩放——组件 0.97、圆形钮 0.90、tab 0.92，100–120ms ease-out，松手回弹**不过冲**（Pressable 统一实现）。
- **Spring 默认**：`damping 1.0 / response 0.3–0.4s`；仅惯性手势（甩动、sheet、松手列表）用 `damping 0.8`。
- **速度交接**：手势释放速度作为 spring 初速度；动量投影 `v/1000 · d/(1−d)`（d≈0.998）定落点。
- **可中断**：动画从当前呈现值起步，永不锁输入。
- **二级页推入（dsh-Go）**：iOS 式水平推入，上一页轻微左移并变暗；返回手势跟手。
- **弹层（dsh-Go）**：底部升起略带阻尼；下拉跟手收起。
- **列表首现（dsh-Go）**：淡入 + 上移 8，逐项错开 ≤30ms，最多前 8 项。
- **状态变化（dsh-Go）**：数值与状态文字交叉淡变；状态点颜色渐变。
- **页头收起（dsh-Go）**：详情页 PageHero 随滚动淡出、标题移进顶栏。
- **空间一致**：进出场同路径；弹层 origin 锚定触发源。边界橡皮筋。
- **降级**：系统「减弱动态效果」→ 全部 cross-fade（统一动效入口处归零）；「减弱透明度」→ 浮层实底、去 blur。
- **多模态**：批准 / 回滚 / 配对成功 → 视觉 + 轻触觉**同帧**。

## 9. 无障碍

- 对比度：primary 底白字 5.5:1；primaryContainer 上 `#2B4A6E` ≈ 7:1；正文 `#1B1C20` 于 background ≈ 14:1——全部 AA。
- 触控目标 ≥ 44dp。
- 动态字体：sp + 弹性布局，200% 缩放不溢出。
- 双编码：diff 用 颜色 + `+/−` 符号；状态用 文字 + 色点。

## 10. Flutter 落地映射

| 设计 | Flutter |
|---|---|
| 色彩 token | `ColorScheme` 定制覆盖（primary 精确 `0xFF3D6B9E`）；token 集中 theme + constants，禁止散落硬编码 |
| 动态取色 | `dynamic_color` 包；品牌色兜底 |
| 浮层材质 | `BackdropFilter(blur 18 + saturation)`；低端机降级 blur 12 / 关闭 |
| 按压反馈 | `Pressable` 组件（AnimatedScale + GestureDetector，onTapDown 即缩放 + 轻触觉） |
| Spring | `SpringSimulation(dampingRatio: 1)`；惯性交互 0.8 |
| 滚动渐隐 | `ShaderMask` 渐变遮罩 + floating header/footer |
| 双栏 / 断点 | `AdaptiveLayout`：按 §4.3 表判定；横屏手机（高<480）强制单栏 |
| 阅读宽度 | `AppSpace.readingWidth = 720` 常量，内容列 `ConstrainedBox` 居中 |
| 列表首现动效 | `FadeInList` / `FadeSlideIn`（index 错开 ≤30ms，前 8 项） |
| 页头收起 | `PageHero` + `SliverAppBar` 折叠 |

# dsh-Go 真机视觉规格（像素底稿）

> 2026-11-10 从用户 OPPO Pad 实机截屏测量（2520x1680 横屏），取代此前从设计文档推断的一切视觉假设。
> 本文件是 ZClient UI 的**最高优先级**视觉事实源；design-system.md 的 dsh-Go 相关章节以本文件为准。

## 全局十条（Flutter 复刻规格）

1. **双栏骨架**：横屏 = 左侧浮动抽屉面板（宽 ~33%屏宽、外边距 12、r36、底 #F7F9FA、浅投影）+ 右侧主区；主区背景 = **135° 对角渐变 #EAF3F8 → #CFE2ED**。
2. **品牌主色唯一：深青 #155E66**，只用于主按钮（新对话）与发送圆钮；全站无第二强调色。
3. **玻璃白体系**：悬浮 chrome（顶栏圆钮/标题胶囊/建议卡/输入卡）= 白色半透明 55%–95%，胶囊 r=h/2、卡 r32–50，无边框或 1px #E5E9EC，阴影 ≤2dp。
4. **卡片配方**：r 32–36、内边距 32、前置图标砖 100×100 r30 粉彩底+同色系线性图标；网格间距 32。
5. **字阶**（px/重/色）：Display 81/600/#1B1E21 · 标题 43/600-700/#1B1E21 · 正文 38-40/400/#23272B · 次要 33-35/400/#8A9199 · 占位 #9AA1A8。
6. **选中语言**：chip 选中 = 实心近黑 #17191C 白字；未选 #EEF0F3 底 #3A3F45 字；不用品牌色做选中。
7. **状态**：绿点 8px #34B26B = 已连接（连接行+顶栏副标题）；说明文字 #6F767E + 琥珀图标。
8. **弹层**：底部 sheet 宽 66%、上圆角 60、磨砂 rgba(243,247,249,.92)，内白卡 r50，键值行（label #5B636B 左 / value #15181B 右，无分隔线），40% 黑蒙层。
9. **输入卡**：r50 近实白；附件 chip #EDF2F5 r30；左 + 圆钮 63px；右下发送圆钮 95px #155E66。
10. **圆度体系**：胶囊/卡32-36/图标砖30/sheet60，全站无直角。

## 首页（聊天空态）骨架

抽屉：品牌行（logo 70px+「DSH」43/700）→ 主按钮行（新对话 pill #155E66 白字 84 高 + 左白圆互换钮）→ 搜索框（r40 #F1F3F5）→ 项目行（文件夹+名 43/700+…）→ 筛选 chips → 时间分组标签 38/#9299A0 → 纯文字会话行 43/400（无头像/时间/箭头）→ 底部身份栏（浅绿图标砖 113 r28 #DFF1E4 + 设备名 43/700 + 绿点已连接 + 两个白圆钮 120：九宫格/齿轮）。
主区：顶栏（汉堡白圆 107 + 标题胶囊白 90% 不透明[主标题 43/700 + 绿点副标题 33] + 模型胶囊）→ 问候（「夜深了」81/600 + 副题 50/400）→ 上下文胶囊（白55%）→ 2×2 建议卡 → 输入卡贴底。

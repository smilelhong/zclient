# ZClient 界面清单与逐屏设计

> **版本** v1.0 · 2026-11-09
> 配合 [design-system.md](./design-system.md)（规则）使用：那份讲"零件怎么做"，这份讲"每屏长什么样"。
> 设计模式参考 [dsh-Go](https://github.com/ccch1mneyyy/dsh-Go) 的 page-design 方案（AGPL-3.0，**仅借鉴设计模式，代码自写，素材不复制**）。

## 0. 五种页面骨架

所有页面归入五种骨架之一；同骨架页面的顶部、间距、分组方式必须一致。

| 骨架 | 用在 | 结构 |
|---|---|---|
| **A 枢纽页** | 设置首页 | 大标题 → 搜索胶囊 → **概览卡**（本页最重要的状态）→ 按意图分组 |
| **B 详情页** | 设备详情、改动、工作流、统计、关于 | **PageHero 页头**（图形+标题+一行状态+2–3 个数据，随滚动收进顶栏）→ 胶囊页签（可选）→ 内容卡片 |
| **C 列表页** | 设备、会话、定时任务 | 大标题 → 状态过滤芯片（可选）→ 按时间/设备分组列表。行结构四段式：图标位 + 主标题 + 副标题 + 右侧元信息/状态点 |
| **D 表单页** | 登录、配对、任务编辑 | 标题+一句话 → 分组输入 → 底部固定主按钮（键盘弹起贴键盘）；错误就地显示 |
| **E 弹层** | 切换设备、通知、确认类 | 拖把手 → 标题行 → 内容 → 至多一个主按钮；圆角 28 |

## 1. 逐屏设计

### A · 首次与配对

**1. 登录（D）** 品牌引导：首屏大留白 + Z 标识 + 一句话（"把 ZCode 装进口袋"）+ 主按钮"登录 ZCode"→ 内嵌 WebView 打开官方页，拿到 `zcodejwttoken` 后自动返回。底部小字：非官方客户端声明。平板：居中卡片（宽 ≤560）。

**2. 扫码配对（D 变体）** 全屏相机取景 + 雾蓝圆角取景框 + 半透明底部说明卡（"对准桌面端 ZCode → 远程控制 二维码"）；右上"粘贴链接"入口 → 手动输入配对链接兜底（输入框 + 连接按钮）。成功 → 设备命名页（D）→ 进入设备列表。

**3. 连接诊断（B，设置子页）** 状态环（连接中=呼吸主色环 / 出错=红）+ 检查项列表（网络 / relay 可达 / token 有效 / 协议版本）+ "重试"主按钮。协议版本过期时全 App 顶部横幅引至此页。

### B · 主导航

**4. 设备列表（C）** ✅ 视觉已定稿（见 mockup）。手机：卡片列表 + FAB"扫码添加" + 底部导航；平板：左栏。行结构四段式：图标位（设备图形）+ 设备名 + 状态副行（在线绿点 · N 个会话进行中）+ 右侧 chevron。空态：EmptyView（设备图形 + "还没有配对的设备" + 单按钮"扫码添加"）。

**5. 设备详情（B）** PageHero：设备图形 + 设备名 + 在线状态 + 数据（会话数 / 今日活动 / 配对天数）。页签：会话 / 用量。会话页签 = 该设备的 C 列表；用量页签 = 本周条形图（按天）+ 累计卡。底部"解除配对"（danger 文本钮，二次确认 E 弹层）。

**6. 会话列表（C）** 顶部状态过滤芯片：`全部`（选中=深炭黑实心白字）/ `进行中` / `待确认` / `已完成`。按设备分组（组标题 = 设备名+状态点），组内会话行：类型图标（对话/任务/工作流）+ 会话名 + 最后活动副行 + 右侧状态（进行中=呼吸点、待确认=主色点、完成=无）。平板：左栏即此列表（宽 248dp，含设备组头部）。空态：EmptyView。

**7. 会话对话流（核心屏，✅ 已定稿 + dsh 范式升级）**
- 顶栏（半透明浮层）：返回 / 标题+设备胶囊（点开 → **E 切换设备抽屉**）/ 更多
- 用户消息：右对齐 primaryContainer 气泡（max 宽 78%）
- **助手消息：全宽无气泡**，结构 = 可折叠**状态行**（`✓ 已完成 · 3 次工具调用` / `● 进行中 · 正在执行 vitest`，chevron 展开工具轨迹）→ 正文（含代码块/工具 chip 内联）→ **尾部元信息行**（`23 秒 · 4 步 · 3.4 万 tokens ›` + 复制 + 更多）
- **交付卡**："交付了 N 个文件" / "改动了 N 个文件" + 文件行（类型图标 + 等宽文件名 + 灰路径 + 右侧 `+N −N`）+ 底部主色链接"查看改动"
- **待确认卡**：左缘 4px 主色 + 命令等宽 + 拒绝(tonal)/批准(fill)（维持定稿）
- 流式：状态行实时变化 + 闪烁光标
- 输入条：半透明浮层大胶囊（+ 附件 / 占位 / mic / 主色圆形发送）
- 会话内历史导航：顶栏下方薄条 `‹ 上一条 / 3/12 / 下一条 ›`（等宽数字）

**8. 改动 Diff（B）** 从交付卡或元信息行进入。PageHero：diff 图形 + 文件数 + `+N −N` 汇总。页签：`文件`（文件行列表，每行红绿数+点击展开单文件 diff）/ `全部`（按文件顺序的完整 diff 流）。diff 行：行号列 + `+`绿底/`−`红底（等宽）。回滚：每文件行尾"回滚"文本钮 → E 确认弹层（danger 描述 + 确认）。

**9. 工作流视图（B）** PageHero：工作流名 + 状态 + 步数统计。垂直步骤条：每步 = 节点（完成✓ / 进行中呼吸 / 失败红 / 待确认主色）+ 步骤名 + 耗时，可展开看该步输出（等宽卡）。失败步带"重试"胶囊。待确认步内嵌待确认卡（同 7）。

### C · 自动化

**10. 定时任务列表（C）** 行：时钟图标位 + 任务名 + cron 人话描述副行（"每天 9:30 · 工作日"）+ 右侧启用开关。空态：EmptyView + "新建定时任务"按钮。

**11. 定时任务编辑（D）** 名称 / 时间 / 重复（胶囊选择）/ **错峰运行**开关（副文本解释）/ 目标会话选择（C 弹层）。底部固定"保存"主按钮；编辑态顶部"删除"danger 文本钮。

### D · 数据与通知

**12. 通知（E 弹层，不设独立页）** 顶栏铃铛（未读=主色点）→ 底部弹层：按时间倒序的事件行（会话图标 + "重构登录模块 · 已完成" + 相对时间），点击直达对应会话。系统通知照 zic 模式（完成/待确认）。"管理通知"链接 → 设置。

**13. 使用统计（B）** PageHero：今日汇总（消息数 / token / 活跃会话，等宽数字+单位次级）。周柱状图（主色，静默网格线）+ 按设备分拆列表（设备行 + 占比条 + 数值）。底部说明：数据仅存本机。

### E · 设置

**14. 设置（A 枢纽）** 搜索胶囊（"搜索设置"）→ 概览卡（账号头像位 + 账号名/登录状态 + 底部"已配对 N 台设备 · 1 台在线"状态条）→ 意图分组：
- 外观：主题（浅色/深色/跟随系统）、品牌色（雾蓝/动态取色）、语言
- 通知：系统通知开关、免打扰时段
- 自动化：定时任务（入口）
- 数据：使用统计（入口）
- 连接：连接诊断（入口）
- 帮助与关于：关于 ZClient、开源许可、隐私说明
行进入子页右侧显示当前值（如"跟随系统"）。

**15. 关于（B）** PageHero：Z 标识 + 版本号 + "检查更新"（有新版→跳浏览器 GitHub Releases）。分组：非官方声明（置顶灰卡）、开源许可（MIT + vendored ZLinker MIT）、隐私说明摘要。

### F · 系统层

**16. 桌面小组件（系统规格）** 2×2：设备名 + 在线点 + 进行中会话数 + 最近事件一行；4×1：设备名 + 状态点。深浅色跟随系统。点击 → 直达对应设备会话列表。

**17. 空态/错误态（EmptyView 组件）** 统一结构：图形（淡主色）/ 标题 / 一句话 / 至多一个按钮。覆盖：无设备、设备离线（会话页顶部横幅+重连按钮）、会话空、断网（全屏）、协议版本过期（横幅+诊断）。

### 弹层组件

**E · 切换设备抽屉（🆕）** 会话顶栏设备胶囊点开。拖把手 + "切换设备"标题 + 关闭钮 → 设备行列表（图标位 + 设备名 + 副行 `本机 · 运行中` / `远程 · macOS` + 右侧状态点，当前设备蓝色对勾）→ 尾行"管理设备 ›"（→ 设备列表）。切设备后当前会话列表整体切换。

| 小组件 | 16 |
